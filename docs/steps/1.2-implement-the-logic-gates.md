# Step 1.2: Implement the 16 logic gates

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

We need Python and Verilog to agree on exactly what every gate ID means.

## What we did

We implemented all 16 possible functions of two Boolean inputs, their soft formulas, and Verilog expressions.

## How it works

List the output for inputs 00, 01, 10 and 11. Read those four output bits as a binary number to get the gate ID. Tests check every gate at all four input combinations.

## Small example

AND has outputs 0001, so its gate ID is 1. XOR has outputs 0110, so its ID is 6.

## Result and its limits

The truth-table/Verilog-expression test and soft-corner test pass. Soft formulas agree with Boolean truth tables when inputs are exactly 0 or 1.
