# Step 1.4: Train the baseline

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

We need a reference model before trying to reduce switching.

## What we did

We trained a 4-layer, 1,000-gate-per-layer digits model for 60 epochs with seed 0 and no switching penalty.

## How it works

The training script uses Adam with learning rate 0.01, batch size 100 and tau 10. It minimizes classification loss and reports soft and hard accuracy during training.

## Small example

An epoch means going through the training images once. Sixty epochs revisit that set sixty times, in shuffled minibatches.

## Result and its limits

The completed run is runs/digits_w1000. Its metrics include the full argument list. Training was already completed; writing this note did not rerun it. The script currently evaluates test data during training; future experiment selection needs a separate validation split.

## Reproduce or inspect

Historical note: that baseline used all 1,347 training-pool examples and
monitored test accuracy. [Step 2.8](2.8-place-and-route.md) corrected future
training to use 1,077 training and 270 validation examples, with final test
evaluation. The command below now uses that corrected protocol, so it does not
exactly reproduce the historical baseline. Historical code is preserved in
commit `fb2d5ae`; do not use its test-monitoring practice for new penalty sweeps.

Run from the repository root:

```bash
.venv/bin/python scripts/train.py --dataset digits --width 1000 --depth 4 --tau 10 --epochs 60 --seed 0 --out runs/digits_reproduce
```
