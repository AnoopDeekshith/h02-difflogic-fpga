# Step 1.8: Export the Verilog core

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

We need a hardware description of the fixed network.

## What we did

We generated dlgn_top.sv with the logic layers, class-score sums, prediction selection and input/output registers.

## How it works

The exporter turns each chosen gate into a Verilog expression and connects it to the saved input indices. Balanced adder trees count ones per class. A strict greater-than comparison preserves the lowest-index tie rule.

## Small example

The XOR neuron connected to inputs 2 and 9 becomes an expression equivalent to input[2] ^ input[9].

## Result and its limits

The original design has two cycles of latency and a valid pipeline aligned with its output. Its input and output registers provide clocked boundaries for later timing analysis.
