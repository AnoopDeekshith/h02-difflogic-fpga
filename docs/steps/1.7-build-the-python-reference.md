# Step 1.7: Build the independent Python reference

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

A separate implementation helps detect mistakes in the trainable model and RTL exporter.

## What we did

We implemented the fixed gate network in NumPy as the golden reference.

## How it works

For each layer, gather the two Boolean inputs for each neuron and look up its selected gate's output. Sum the final outputs by class. Select the largest score, breaking ties in favor of the lowest class index.

## Small example

If class scores are [3, 7, 7], the prediction is class 1, not class 2. Both have 7, so the earlier index wins.

## Result and its limits

The saved training metrics confirm that hard PyTorch scores multiplied by tau match NumPy's raw integer scores. The comparison allows small floating-point roundoff on the PyTorch side.
