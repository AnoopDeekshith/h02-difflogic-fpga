# Step 2.5: Establish the FPGA tool flow

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

We need working implementation tools before interpreting neural-network placement or timing failures.

## What we did

We selected the iCE40UP5K in the SG48 package and installed nextpnr-ice40 and IceStorm alongside Yosys.

## How it works

A small 24-bit counter checks the full flow: synthesis, packing, placement, routing, timing against 12 MHz, and bitstream generation. Its clock and LED have fixed board pins.

## Small example

This is a tool check like testing a printer with a small test page before printing a long report.

## Result and its limits

The counter passed the 12 MHz target; its post-route estimated Fmax was 79.74 MHz. That number belongs to the counter, not the neural network. The generated bitstream was not programmed onto hardware.
