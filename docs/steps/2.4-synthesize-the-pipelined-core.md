# Step 2.4: Synthesize the pipelined core

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

Extra pipeline registers have a hardware cost, and register boundaries change optimization opportunities.

## What we did

We synthesized the pipelined core with the same Yosys flow used for the original core.

## How it works

Map rtl_pipe/dlgn_top.sv to iCE40 primitives and compare the synthesis statistics with rtl_comb.

## Small example

The original core uses 268 flip-flops; the pipelined core uses 3,523. Registers hold intermediate layer outputs between clocks.

## Result and its limits

Core-only counts: 4,528 LUT4s, 3,523 flip-flops and 123 carry cells. Do not add LUT and flip-flop counts to predict fit: some can share a logic cell, but only when compatible. Step 2.7 later finds that the complete pipelined UART design needs more cells than the UP5K has.
