# Step 2.1: Synthesize the original core

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

Verilog source alone does not tell us how much FPGA hardware the network needs.

## What we did

We mapped the original core to the iCE40's LUT, register and carry primitives using Yosys.

## How it works

The synthesis script reads dlgn_top.sv, runs synth_ice40, writes a mapped JSON netlist and extracts the resource counts from the statistics report.

## Small example

A neuron that simply forwards input A can become a wire. Several logic expressions may also combine into one LUT, so 4,000 logical gates do not mean 4,000 FPGA LUTs.

## Result and its limits

Core-only counts: 2,929 LUT4s, 268 flip-flops and 123 carry cells. These exclude the UART adapter. Synthesis does not establish routing success or achievable clock speed.
