# Step 2.2: Add pipeline registers

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

Shorter logic paths between registers may support a faster clock.

## What we did

We generated a second architecture with a register after each of the four logic layers.

## How it works

The same exporter uses --pipeline. Gate choices and connections stay the same, while each layer stores its output for the next clock. The valid indicator is delayed alongside the data.

## Small example

Like an assembly line, several images can occupy different stages at once. One image takes six cycles to finish, while a new image can enter every cycle.

## Result and its limits

Core latency changes from 2 to 6 cycles. That does not by itself establish higher throughput: clock speed still needs implementation timing analysis.
