# Step 1.1: Prepare the digits data

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

Logic gates need bits, while a digit image starts as pixel brightness values.

## What we did

We used scikit-learn's bundled 8×8 digits and encoded every pixel with three threshold comparisons.

## How it works

Normalize pixel values by dividing by 16. Compare each pixel against 0.25, 0.5 and 0.75. Split the 1,797 images into 1,347 training and 450 test images, preserving class proportions with seed 0.

## Small example

A brightness of 0.60 becomes [1, 1, 0]. An image has 64 pixels × 3 bits = 192 input bits.

## Result and its limits

The baseline's saved test array has 450 rows and 192 Boolean columns. This encoding is also what the UART interface expects; it does not receive raw grayscale pixels.
