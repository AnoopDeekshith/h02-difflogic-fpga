# Step 1.9: Generate reference vectors and a testbench

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

Simulation needs both input images and the exact answers it should expect.

## What we did

We generated hexadecimal input files, expected scores, expected classes and a self-checking testbench.

## How it works

Compute golden scores using NumPy. Pack input bits and class scores consistently into hexadecimal rows. The testbench reads these files, streams inputs and checks results whenever out_valid is asserted.

## Small example

Input bit 0 is the least-significant bit in x.hex. Class 0's score occupies the lowest score bits in exp_scores.hex.

## Result and its limits

The export includes x.hex, exp_scores.hex, exp_class.hex and tb_dlgn.sv. Checking every score can catch bugs that would still leave the predicted class unchanged.
