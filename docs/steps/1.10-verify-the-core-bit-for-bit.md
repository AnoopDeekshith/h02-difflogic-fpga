# Step 1.10: Verify the core bit for bit

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

Correct recognition in Python does not establish that the hardware translation is correct.

## What we did

We simulated the trained core and compared every output score and predicted class against the NumPy reference.

## How it works

Verilator compiles the generated RTL and testbench. The testbench sends one image per clock and compares each valid result with its corresponding expected row. The shell runner requires a PASS result.

## Small example

A Python score of 37 and a Verilog score of 36 fail verification even if both still predict digit 5.

## Result and its limits

The original and pipelined cores each passed 450/450 saved test images. This is tested agreement for those vectors; it is not a proof over every possible 192-bit input.
