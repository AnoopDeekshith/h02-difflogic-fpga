# Step 2.6: Build the UART board interface

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

The core exposes 270 port bits, so it needs a practical interface for a small board.

## What we did

We wrapped the core with serial input/output and board reset logic, exposing only clock, button reset, RX and TX.

## How it works

The adapter gathers 24 encoded image bytes, submits one core request and waits for its result. It replies with a header, the predicted class and ten score bytes. The laptop must wait for the full reply before sending another request.

## Small example

Instead of wiring all 192 image bits to pins, we send 24 bytes through the board's existing USB-to-UART bridge.

## Result and its limits

Both architectures passed all 450 images through simulated serial pins. UART-complete synthesis counts are 3,440 LUTs/648 flip-flops for the original and 5,059 LUTs/3,903 flip-flops for the pipelined version. These are not placement results. A live host client and physical-board testing remain pending.
