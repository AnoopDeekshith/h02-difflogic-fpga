# Step 2.3: Verify the pipelined core

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

Registers can introduce data/valid alignment bugs even when the logic equations are unchanged.

## What we did

We checked the pipelined core with the same images and golden scores used for the original core.

## How it works

The testbench sends images on consecutive clocks. It compares each result only when the delayed valid signal is asserted, preserving the original request order.

## Small example

The prediction for image A must not accidentally be compared with image B's scores just because extra registers delayed A.

## Result and its limits

The pipelined core passed 450/450 images, including every score and predicted class. The random-network pipelined regression also passes.
