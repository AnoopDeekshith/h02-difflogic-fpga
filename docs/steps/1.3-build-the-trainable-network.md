# Step 1.3: Build the trainable network

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

Choosing a discrete gate directly is hard to train with gradients.

## What we did

We built a PyTorch network in which each neuron learns a mixture of 16 gate rules.

## How it works

Each neuron has two connections chosen at initialization and 16 trainable weights. A softmax converts weights into mixture probabilities. The connections stay fixed; training changes the gate-selection weights. The last layer is divided into groups, and each group's outputs are summed to make a class score.

## Small example

With width 1,000 and 10 digits, each digit gets a group of 100 final-layer outputs. If 37 are one, the raw score is 37; the training head divides it by tau = 10.

## Result and its limits

The implementation supports soft and hard evaluation. Model construction checks that width divides evenly into the number of classes.
