# Step 1.6: Measure recognition accuracy

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

Locking a mixture to a single gate can change predictions; we need to quantify that change.

## What we did

We compared soft-model and hard-model recognition on the same 450 test images.

## How it works

Count predictions that equal the dataset label and divide by 450. Separately subtract hard accuracy from soft accuracy to obtain the discretization gap.

## Small example

Soft evaluation got 422/450 correct; hard evaluation got 421/450 correct. The difference is one image, or about 0.22 percentage points.

## Result and its limits

Saved soft accuracy is 93.78%; hard and NumPy reference accuracy are 93.56%. Recognition accuracy answers whether the digit was correct, not whether hardware faithfully implemented the model.
