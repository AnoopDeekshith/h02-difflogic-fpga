# Step 3.1: Measure logical switching in Python

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

We need a baseline activity measure before training the network to switch less.

## What we did

We counted changes in every hard gate's settled output between consecutive saved test images.

## How it works

Run the NumPy model and retain all layer outputs. Concatenate the 4,000 logical gate outputs for each image, compare adjacent rows, and average the Boolean change indicators. There are 449 transitions between 450 images.

## Small example

For outputs [0, 1, 1, 0, 1], three of four transitions change value, giving a rate of 0.75.

## Result and its limits

The saved average is 0.349760 changes per logical gate per image transition. It depends on image order and excludes glitches, clocks, registers and routing capacitance. It is not a power or energy measurement.
