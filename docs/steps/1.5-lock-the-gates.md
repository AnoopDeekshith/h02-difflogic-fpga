# Step 1.5: Lock the gates to fixed rules

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

An FPGA needs fixed gate functions instead of a floating-point mixture of rules.

## What we did

We selected each neuron's highest-weight gate and saved the fixed network as JSON.

## How it works

Take argmax across a neuron's 16 weights. Keep the chosen gate ID and its two input indices. Repeat across all four layers. The JSON also records dimensions, class count and tau.

## Small example

If XOR has the largest weight, that neuron becomes an XOR gate, regardless of the other 15 mixture weights.

## Result and its limits

model.json contains 4,000 gate choices and their connections. It is the handoff used by the NumPy evaluator and both exporters. It is a hard network, not a saved checkpoint of the soft PyTorch weights.
