# Step 4.2: Preserve the unpenalized baseline

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

We need a fixed comparison point to judge whether switching-aware training improves anything.

## What we did

We retained the lambda=0 hard network, test inputs, labels, metrics and generated hardware reports.

## How it works

The baseline metrics record training arguments, seed, accuracy, logical switching and gate counts. Future penalty runs should use separate output folders and the same evaluation procedure, without overwriting this baseline.

## Small example

If a future model switches less, compare its accuracy and hardware cost too. A reduction that comes only from predicting one constant digit would not be a useful result.

## Result and its limits

The current baseline is runs/digits_w1000. It is stored locally under a gitignored runs/ directory; final artifact archival is still step 7.3. No soft-model training checkpoint is saved, so model.json cannot resume soft training.
