# Step 1.11: Run the regression tests

Status: completed. Notes recorded November 13, 2026.

## Why we needed this

Repeatable tests help catch mistakes when we change the exporter or interface.

## What we did

We ran the core/gate tests and UART regressions. Step 2.7 also adds constraint and synchronizer checks.

## How it works

The original tests cover the truth tables, soft formulas and random-network RTL for both register configurations. UART tests exercise real serial pins, reference scores, packet recovery, input padding and tied scores. Constraint tests use a small synthesized wrapper and deliberately corrupt its constraints or wiring.

## Small example

A test intentionally bypasses the second RX synchronizer register; the constraint checker must reject that unsafe connection.

## Result and its limits

Step 2.7 had 14 passing tests. Step 2.8 brings the suite to **45 passing tests**:
14 earlier cases, 16 independently written exhaustive head-pipeline cases,
11 artifact-validation cases and 4 data-partition cases. The exhaustive cases
check 16,384 synthetic inputs. Simulator-dependent tests require the relevant
tool; a skipped check is not a hardware verification result. See
[PROJECT_CONTEXT.md](../PROJECT_CONTEXT.md) for the latest result and
[the independent review](../reviews/step-2.8-independent-review.md) for its scope.

Step 2.9 adds 18 independently written archived-timing report cases, bringing
the suite at that step to **63 passing tests**. These check changed hashes, stale
parameters, failed attempts, invalid clock/path evidence and older records
missing tool identity. See [the timing walkthrough](2.9-read-and-verify-clock-timing.md)
and its [independent review](../reviews/step-2.9-independent-review.md).

Step 2.10 adds 8 independent performance cases, bringing the current suite to
**71 passing tests** (15.14 seconds, no skips). They check all four register
configurations, input bubbles, full UART stop-bit boundaries, the shipped
performance bench and model/workload matching. See
[step 2.10](2.10-compare-latency-and-throughput.md) and its
[review](../reviews/step-2.10-independent-review.md).
